# 名古屋・高山家庭旅行網站（手機版原型）

## 使用方式
這是一個手機優先的靜態網站原型。請把整個資料夾部署到任何靜態網站服務（例如 GitHub Pages、Netlify、Vercel），即可用手機 Safari / Chrome 開啟。

## 目前功能
- 家人版「今天」：目前位置、下一站、當日時間軸、三間餐廳候選、今晚住宿
- 六日行程總覽
- AI 問答原型：可回答行程、住宿、餐廳、回程航班等
- 我的旅程：收納訂單截圖
- 管理模式：可改目前位置、狀態、下一站、交通、餐廳候選
- 使用 Noto Sans TC 開源黑體；整體大地色，橘色只做重點 highlight

## 重要限制
此第一版是純前端原型，管理頁修改只存在「同一台裝置、同一個瀏覽器」的 localStorage。
若要你在自己的手機更新後，爸爸媽媽／姊姊／老公的手機立即同步，需要接 Supabase / Firebase 等雲端資料庫。
AI 目前是本地規則式回答；若要真正讀取訂單圖片、餐廳、住宿與你上傳的資料，需要接 AI API 與雲端儲存。

## 圖片
住宿與景點畫面支援放入網路圖片；目前部分使用網路公開圖片與你提供的訂單截圖做原型。
